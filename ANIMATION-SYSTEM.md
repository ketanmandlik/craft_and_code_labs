# Animation system

GSAP handles masked heading reveals, dialog entry and ScrollTrigger sequences. Lenis shares the GSAP ticker on desktop with a fine pointer. Touch and reduced-motion browsing use native scrolling. Desktop pinning is limited to the manifesto and concept rail, with a native snap rail on touch and in reduced motion.

The R3F sculpture renders on the same ticker at a capped cadence while visible. Its morph parameter follows scroll or the four manual controls. Procedural WebP plates cover initialization, restricted motion and WebGL failure. High-frequency camera and pointer values live in refs.

GSAP scopes own their timelines and scroll triggers. Media query branches clean up on breakpoint changes. The dialog uses native modal focus handling, locks background scrolling and adapts to the visual viewport on mobile.
